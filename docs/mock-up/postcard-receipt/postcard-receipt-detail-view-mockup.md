## PostcardReceipt 詳細画面モック（v1）

- **画面ID**: `REC004`
- **画面名**: 受取履歴詳細
- **設計書**: `docs/design/postcard-receipt-v1-design.md`

---

### 1. 画面レイアウト（読み取り専用）

- **上部エリア**
  - 左上: 画面タイトル「受取履歴詳細」
  - タイトル直下（大きめ）: 送り主表示名
  - 右上: 「編集」（Primary）、「削除」、「戻る」（一覧へ）

#### 1.1 受取情報ブロック

| ラベル | 表示内容 | 対応ドメイン |
| --- | --- | --- |
| 受取日 | 例: `2026/01/03` | `receivedAt` |
| 種別 | 例: `年賀状` | `category` |
| メモ | 複数行テキスト | `memo` |

#### 1.2 送り主ブロック

| ラベル | 表示内容 | 備考 |
| --- | --- | --- |
| 紐付け | あり / なし | |
| 住所録 | 表示名 + 住所 1 行 | `addressEntryId` がある場合。リンクで ADDR004 へ |
| 表示名 | `senderDisplayName` | 未紐付け時、または補足表示 |

- 紐付け先 AddressEntry が archived の場合: 「（アーカイブ済みの宛名）」+ 可能なら当時の表示名

#### 1.3 システム情報

| ラベル | 表示内容 |
| --- | --- |
| ID | UUID |
| 作成日時 / 最終更新日時 | `createdAt` / `updatedAt` |

---

### 2. アクション・遷移

- **編集** → `REC003`
- **削除** → 確認後 `delete_postcard_receipt` → 一覧（`REC001`）
- **住所録リンク** → AddressEntry 詳細（`ADDR004`）
- **戻る** → 一覧（`REC001`）

---

### 3. UX メモ

- 削除済みレコードへの直接アクセスは v1 非想定（一覧から除外）
- 編集保存後はフラッシュ「受取履歴を更新しました。」
