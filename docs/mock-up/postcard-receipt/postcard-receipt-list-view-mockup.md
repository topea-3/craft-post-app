## PostcardReceipt 一覧画面モック（v1）

- **画面ID**: `REC001`
- **画面名**: 受取履歴一覧
- **設計書**: `docs/design/postcard-receipt-v1-design.md`

---

### 1. 画面レイアウト（テーブル一覧）

- **上部エリア**
  - 左上: 画面タイトル「受取履歴一覧」
  - 右上: ボタン群
    - 「新規作成」ボタン（Primary）
    - 「フィルタ」トグル（フィルタエリアの開閉）
- **検索・フィルタエリア（折りたたみ可）**
  - フリーテキスト検索
    - プレースホルダ: 「表示名・メモで検索」
    - 対象: `senderDisplayName`, 紐付け先 `AddressEntry` の表示名, `memo`
  - 受取年セレクト
    - 選択肢: 年（例: 2026, 2025, 2024, …）/ 「全期間」
    - 条件: `receivedAt` の年
  - 種別セレクト
    - 選択肢: 全種別 / 年賀状 / 喪中はがき / その他
  - 相手（住所録）フィルタ
    - 「相手を選択」ボタン → AddressEntry 選択ダイアログ（active のみ）
    - 選択中はチップ表示 + クリア
- **一覧テーブル**
  - 行クリック: 詳細画面（`REC004`）へ遷移
  - 右端: 編集 / 削除操作
  - ページネーション: フッター（`PaginationControls`）

#### テーブルカラム案

| 順序 | カラム名 | 内容 / 対応ドメイン | 備考 |
| --- | --- | --- | --- |
| 1 | 受取日 | `receivedAt` | フォーマット例: `2026/01/03` |
| 2 | 種別 | `category` 表示名 | バッジ表示可 |
| 3 | 送り主 | 紐付け時: AddressEntry 表示名 / 未紐付け: `senderDisplayName` | 太字 |
| 4 | メモ（抜粋） | `memo` 先頭 30 文字 | ホバーで全文 |
| 5 | 操作 | 「編集」/ 「削除」 | |

- **表示対象レコード**
  - 条件: `deletedAt` 未設定（DB では `deleted_at IS NULL`）
  - デフォルトソート: `receivedAt` 降順

---

### 2. アクションと遷移

- **新規作成** → 作成画面（`REC002`）
- **行クリック** → 詳細画面（`REC004`）
- **編集** → 編集画面（`REC003`）
- **削除**
  - 確認ダイアログ後、`deletedAt` を設定（論理削除）
  - 成功後は一覧から非表示

---

### 3. 状態・UI 挙動メモ

- **空状態**: 「まだ受取履歴が登録されていません。」+ 新規作成ボタン
- **検索 0 件**: 「該当する受取履歴が見つかりませんでした。」+ 条件クリア
