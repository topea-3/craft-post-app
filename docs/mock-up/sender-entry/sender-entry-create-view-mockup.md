## SenderEntry 作成画面モック（v1）

- **画面ID**: `SEN002`
- **画面名**: 差出人登録（新規作成）

---

### 1. 画面レイアウト（フォーム）

- **上部エリア**
  - 左上: 画面タイトル「差出人登録（新規作成）」
  - 右上: 「キャンセル」リンク（一覧へ戻る）
- **フォーム本体**

#### 1.1 差出人ラベル（選択用）


| 項目名 | UI コンポーネント | 対応ドメイン              | 備考                                     |
| --- | ---------- | ------------------- | -------------------------------------- |
| ラベル | テキスト入力     | `SenderLabel.value` | **必須** / 非アーカイブ内で一意（DB 制約は作らずアプリ側チェック） |


#### 1.2 氏名（主たる氏名・連名）


| 項目名        | UI コンポーネント   | 対応ドメイン                       | 備考                  |
| ---------- | ------------ | ---------------------------- | ------------------- |
| 主たる氏名（姓）   | テキスト入力       | `primaryName.last`           | **必須**              |
| 主たる氏名（名）   | テキスト入力       | `primaryName.first`          | **必須**              |
| 主たる氏名（カナ姓） | テキスト入力       | `primaryName.kanaLast`       | 任意                  |
| 主たる氏名（カナ名） | テキスト入力       | `primaryName.kanaFirst`      | 任意                  |
| 連名         | 繰り返し行＋テキスト入力 | `coRecipients: PersonName[]` | 行追加／削除。**0 件〜 4 件** |


連名行の入力（各行）:

- 姓（`coRecipients[].last`）: テキスト入力 / 必須
- 名（`coRecipients[].first`）: テキスト入力 / 必須
- カナ姓（`coRecipients[].kanaLast`）: 任意
- カナ名（`coRecipients[].kanaFirst`）: 任意

#### 1.3 差出人の表示名プレビュー

- `joinRecipients(primaryName, coRecipients)` を基にした「差出人（表示名）」を画面上部/フォーム下部でプレビュー表示
- 表示名の結合は `docs/domain/address-domain-v1.md` の `joinRecipients(primaryName, coRecipients)` に準拠する（同姓省略など）

#### 1.4 住所情報


| 項目名      | UI コンポーネント  | 対応ドメイン               | 備考                    |
| -------- | ----------- | -------------------- | --------------------- |
| 郵便番号     | テキスト入力（7 桁） | `PostalCode.value`   | **必須** / `1234567` 想定 |
| 都道府県     | セレクトボックス    | `Address.prefecture` | **必須** / プリセット選択      |
| 市区町村     | テキスト入力      | `Address.city`       | **必須**                |
| 町名・番地    | テキスト入力      | `Address.street`     | **必須**                |
| 建物名・部屋番号 | テキスト入力      | `Address.building`   | 任意                    |


#### 1.5 電話番号（任意）


| 項目名  | UI コンポーネント | 対応ドメイン              | 備考                       |
| ---- | ---------- | ------------------- | ------------------------ |
| 電話番号 | テキスト入力     | `phoneNumber.value` | 任意。入力形式は緩め（ハイフン有無どちらも許容） |


---

### 2. ボタン・アクション

- **画面下部ボタンエリア**
  - 左: 「キャンセル」ボタン（セカンダリ）
    - クリック → 確認ダイアログ（編集中の場合）
      - 「編集中の内容を破棄して一覧に戻ります。よろしいですか？」
    - 確認後 → 一覧画面（`SEN001`）へ遷移
  - 右: 「保存」ボタン（Primary）
    - クリック → バリデーション
    - 問題なければ `CreateSenderEntry` を実行
    - 成功後の遷移先候補:
      - パターン A: 一覧画面（`SEN001`）へ戻る
      - パターン B: 作成したエントリの詳細画面（`SEN004`）へ遷移

---

### 3. バリデーションとエラー表示

- **必須項目**
  - ラベル（`SenderLabel.value`）
  - 主たる氏名（`primaryName.last` / `primaryName.first`）
  - 郵便番号（`postalCode`）
  - 都道府県・市区町村・町名・番地（`Address.prefecture` / `city` / `street`）
  - 住所（`Address`）として必須 3 項目が揃っていること
- **エラー表示**
  - フィールド単位に赤文字メッセージ表示（該当フィールド下）
  - まとめメッセージ（フォーム上部）:
    - 「入力内容に不備があります。赤字の項目を修正してください。」
- **連名上限**
  - `coRecipients` は **0〜4 件**。超過しようとした場合は UI で行追加を無効化、または明示メッセージ表示
- **ラベル制約**
  - 非空
  - 最大 250 文字
