## SenderEntry 選択画面モック（印刷/送付フロー v1）

- **画面ID**: `SEN005`
- **画面名**: 差出人選択

---

### 1. 画面レイアウト（選択ステップ）

- **上部エリア**
  - 左上: ステップタイトル「差出人選択」
  - 右上: （任意）戻るリンク

- **内容エリア**
  - 現在選択中の宛名（`AddressEntry.id`）に紐づく差出人を表示
  - 差出人の選択 UI（例: ラジオボタン、カード一覧、セレクトボックス）

---

### 2. 初期選択ルール（v1 確定）

この画面では、対象の `AddressEntry`（印刷に使う宛名）を前提に、以下の優先順位で初期選択する。

1. **初期選択（宛名に紐づきがある場合）**
   - 対象の `AddressEntry.id` に一致する `SenderAddressLink` が 1 件あり、
     その紐づく `SenderEntry` の `archivedAt` が未設定（有効）であれば
   - その `SenderEntry` を選択状態にする

2. **初期選択（紐づきが無い／候補が無い場合）**
   - 全体の有効な `SenderEntry`（`archivedAt` 未設定）のうち、
     `updatedAt` が最新のものを選択
   - （v1 の方針として、自動的なリンク付けはしない想定。ただし実装側の最終判断は要確認）

3. **未登録時**
   - 有効な `SenderEntry`（`archivedAt` 未設定）が 0 件の場合:
     - 「差出人を登録してください」
     - 差出人登録画面への導線（`SEN002`）を表示

---

### 3. 選択と確定アクション

- **差出人の選択**
  - ユーザーが別の差出人を選択した場合、次工程に進む前に以下を反映する前提:
    - `SenderAddressLink` は宛名 1 件あたり紐づく差出人は高々 1 件
    - 既に別の差出人に紐づいている場合は、置き換え確認が必要

- **確定ボタン（例: 「この差出人で進む」）**
  - クリック → 選択した差出人を印刷スナップショットに利用する
  - （必要なら）`SenderAddressLink` を付け替え

補足（ドメイン整合）:

- 印刷ジョブ/プレビュー作成時に `SenderEntry` をスナップショット保存する
  - `senderId`
  - `senderSnapshot`（印刷に使った実値）

---

### 4. 画面上の表示項目（差出人カード例）

- ラベル: `SenderLabel.value`
- 表示名: `joinRecipients(primaryName, coRecipients)`
- 郵便番号・住所: `PostalCode.formatted` / `Address.toSingleLine()`
- 最終更新日時: `updatedAt`（任意表示。選択候補の根拠提示として使う）
