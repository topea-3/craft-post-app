## SenderEntry 一覧画面モック（v1）

- **画面ID**: `SEN001`
- **画面名**: 差出人一覧

---

### 1. 画面レイアウト（テーブル一覧）

- **上部エリア**
  - 左上: 画面タイトル「差出人一覧」
  - 右上: ボタン群
    - 「新規作成」ボタン（Primary）
- **一覧テーブル**
  - 行クリック: 詳細画面へ遷移（`SEN004`）
  - 操作（右端）: 「編集」／「アーカイブ」など
  - ページネーション: フッター部（シンプルな「前へ／次へ＋ページ番号」）

#### テーブルカラム案


| 順序  | カラム名     | 内容 / 対応ドメイン                                 | 備考                          |
| --- | -------- | ------------------------------------------- | --------------------------- |
| 1   | ラベル      | `SenderLabel.value`                         | 強調表示（太字でも可）                 |
| 2   | 差出人（表示名） | `joinRecipients(primaryName, coRecipients)` | 算出結果を 1 行表示                 |
| 3   | 郵便番号     | `PostalCode.formatted`                      | 例: `123-4567`               |
| 4   | 住所       | `Address.toSingleLine()`                    | 長い場合は末尾 `…`                 |
| 5   | 最終更新日時   | `updatedAt`                                 | フォーマット例: `2026/03/10 08:34` |
| 6   | 操作       | `編集` / `アーカイブ`                              | アイコンでも可                     |


---

### 2. 表示対象・ソート

- **表示対象**
  - `archivedAt` が未設定（有効）の `SenderEntry` のみ表示
  - `archivedAt` が設定されているエントリは通常一覧から非表示
- **ソート（v1 確定）**
  - `updatedAt` **降順のみ**（固定）
  - 検索・オプションソートは提供しない（差出人が大量に増えない前提）

---

### 3. アクションと遷移

- **新規作成ボタン**
  - クリック → 作成画面（`SEN002`）へ遷移
- **行クリック**
  - 詳細画面（`SEN004`）へ遷移
- **編集**
  - 操作カラムの「編集」クリック → 編集画面（`SEN003`）へ遷移
- **アーカイブ**
  - 操作カラムの「アーカイブ」クリック
  - 確認ダイアログ表示
    - 「この差出人をアーカイブしますか？一覧からは非表示になりますが、データは保持されます。」
  - 実行後:
    - `archivedAt` にアーカイブ日時を設定（`updatedAt` は変えない）
    - 一覧から非表示（再読込）

---

### 4. 状態・UI 挙動メモ

- **空状態（0 件）**
  - 「まだ差出人が登録されていません。」
  - 「新規作成」ボタンを中央に強調表示
