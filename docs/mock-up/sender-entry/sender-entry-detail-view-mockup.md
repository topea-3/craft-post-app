## SenderEntry 詳細画面モック（v1）

- **画面ID**: `SEN004`
- **画面名**: 差出人詳細

---

### 1. 画面レイアウト（読み取り専用ビュー）

- **上部エリア**
  - 左上: 画面タイトル「差出人詳細」
  - タイトル直下（大きめ表示）:
    - 差出人表示名（`joinRecipients(primaryName, coRecipients)`）
    - 例: `山田 太郎・花子`
  - 右上: ボタン群
    - 「編集」ボタン（Primary）
    - 「アーカイブ」メニュー
    - 「戻る」リンク（一覧へ `SEN001`）
- **内容エリア**
  - 1 カラム（読みやすさ優先）

#### 1.1 基本情報ブロック


| ラベル       | 表示内容                    | 対応ドメイン                                      |
| --------- | ----------------------- | ------------------------------------------- |
| ラベル       | 例: `自宅`                 | `SenderLabel.value`                         |
| 差出人（表示名）  | `山田 太郎・花子`              | `joinRecipients(primaryName, coRecipients)` |
| 差出人（カナ表示） | `ヤマダ タロウ・ハナコ`（形式は実装に準拠） | `primaryName.dispalyKana` 等                 |
| 主たる氏名     | 例: `山田 太郎`              | `primaryName.display`                       |
| 連名        | 例: `山田 花子`              | `coRecipients[].display`                    |


#### 1.2 住所情報ブロック


| ラベル      | 表示内容                     | 対応ドメイン                   |
| -------- | ------------------------ | ------------------------ |
| 郵便番号     | 例: `123-4567`            | `PostalCode.formatted`   |
| 都道府県     | 例: `東京都`                 | `Address.prefecture`     |
| 市区町村     | 例: `渋谷区`                 | `Address.city`           |
| 町名・番地    | 例: `神南 1-1-1`            | `Address.street`         |
| 建物名・部屋番号 | 例: `○○ビル 3F`             | `Address.building`       |
| 住所（1 行）  | `Address.toSingleLine()` | `Address.toSingleLine()` |


#### 1.3 電話番号ブロック（任意）

- ラベル: 「電話番号」
- 未入力の場合: 空表示（もしくは「未設定」）
- 内容: `phoneNumber.value`

#### 1.4 システム情報ブロック


| ラベル    | 表示内容                  | 対応ドメイン      |
| ------ | --------------------- | ----------- |
| ID     | UUID                  | `id`        |
| 作成日時   | 例: `2026/03/10 08:34` | `createdAt` |
| 最終更新日時 | 例: `2026/03/11 12:01` | `updatedAt` |
| 状態     | 例: `有効` / `アーカイブ済み`   | `archivedAt`（未設定＝有効。API では `archived` 真偽でも可） |


---

### 2. 紐づき宛名（読み取り専用）

- 表示項目（例）:
  - 宛名表示名（`AddressEntry` の表示表現に従う）
  - 郵便番号／住所の 1 行表現

---

### 3. アクション・遷移

- **編集ボタン**
  - クリック → 編集画面（`SEN003`）へ遷移
- **アーカイブ操作**
  - 「アーカイブ」選択 → 確認ダイアログ:
    - 「この差出人をアーカイブしますか？一覧からは非表示になりますが、データは保持されます。」
  - 実行後:
    - `archivedAt` を設定してアーカイブ（`updatedAt` は変えない）
    - 紐づく宛名とのリンクを削除
    - 一覧画面から非表示（`SEN001`）
- **戻るリンク**
  - 一覧画面（`SEN001`）へ戻る
