## 1. 画面レイアウト

専用画面 `/print/select`（入口は `/print/type` = PRT000）。

```
+------------------------------------------------------------------+
| 印刷対象の選択                                    選択: 11 / 200 |
+------------------------------------------------------------------+
| （テスト印刷期間かつ年賀状のとき）                                  |
| ℹ 現在はテスト印刷期間です。印刷はできますが、送付履歴は作成されません。 |
+------------------------------------------------------------------+
| [検索...]  （既存一覧と同型）                                      |
+------------------------------------------------------------------+
| ☐ | 氏名+敬称      | 住所           | 差出人（紐づき）  | 状態   |
| ☑ | 山田 太郎 様   | 東京都...      | 自宅            | OK     |
| ☐ | 佐藤 花子 様   | 大阪府...      | （未紐づけ）     | 除外   |
| ☐ | 高橋 次郎 様   | ...            | 自宅            | 喪中   |
| ☐ | 鈴木 一郎 様   | ...            | 実家            | OK     |
+------------------------------------------------------------------+
| ⚠ 差出人未紐づけ／archived、または喪中のため印刷対象外の行があります。 |
|   [住所録で差出人を紐づけてから再選択 →]                          |
+------------------------------------------------------------------+
|                              [キャンセル]  [確認へ進む →]         |
+------------------------------------------------------------------+
```

---

## 2. 操作

| 操作 | 挙動 |
|------|------|
| 行チェック | 複数選択（最大 200 件）。**状態「除外」「喪中」行はチェック不可** |
| 差出人列 | 読み取り専用。`SenderAddressLink` の有無を表示 |
| 状態「除外」 | 紐づき無し / 差出人 archived → **チェック不可**（選択カウンタにも含めない） |
| 状態「喪中」 | 種別が年賀状かつ送付年が決定できるとき、`receipt_year = 送付年-1` の喪中受取あり → **チェック不可**。差出人除外と同時なら「喪中」を優先表示 |
| 確認へ進む | 有効 1 件以上必須。`resolve_print_job_items` を呼び出し。**AddressEntry archived / not found が混入していればコマンド失敗**（PRT002 へ進まない） |
| 除外アラート | 差出人除外・喪中に応じ表示。住所録編集（差出人リンク）への導線 1 行 |
| キャンセル | `printJobDraft` を破棄して離脱 |

---

## 3. ジョブ状態

- 選択 `addressEntryId[]` のみを `sessionStorage.printJobDraft` に保存（`printJobId` / `postcardType` は**含めない**）
- 種別は PRT000 で確定済みの `printPostcardType` を参照（本画面では変更しない）
- ページリフレッシュ時は本画面へ戻す（state 喪失防止）
- archived `AddressEntry` は一覧に表示しない（既存一覧方針）
- **入場時 prune**: 表示中の検索・ページ `items` は使わない。リクエスト時点の `draft.addressEntryIds` を `filter_active_address_entry_ids`（上限 200）へ渡し、**差集合で適用**（結果で draft を置換しない）。prune 中に追加した ID は残す。「N 件は削除またはアーカイブ済みのため選択から外しました」。一覧未取得・取得失敗・filter IPC/DB 失敗では draft を触らない
- **resolve 失敗時（方針 B）**: エラーの offending ID を draft から除外し本画面に残留。残りで再実行可

---

## 4. 遷移

- 有効件数 0 → 進めない
- `resolve` が AddressEntry archived / not found で失敗 → エラー表示 + draft から該当 ID 除外。PRT001 残留（PRT003 へ進まない）
- 有効件数 ≥ 1 かつ resolve 成功 → PRT002 → PRT003
