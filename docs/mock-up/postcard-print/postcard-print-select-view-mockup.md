# はがき宛名面 印刷対象選択モック（v1）

- **画面 ID**: `PRT001`
- **画面名**: 印刷対象選択
- **設計書**: [postcard-address-print-v1-design.md](../../design/postcard-address-print-v1-design.md)

---

## 1. 画面レイアウト

住所録一覧（`ADD001`）に「印刷」入口を追加するか、専用画面として `/print/select` を用意する。

```
+------------------------------------------------------------------+
| 印刷対象の選択                                    選択: 11 / 200 |
+------------------------------------------------------------------+
| [検索...]  （既存一覧と同型）                                      |
+------------------------------------------------------------------+
| ☐ | 氏名+敬称      | 住所           | 差出人（紐づき）  | 状態   |
| ☑ | 山田 太郎 様   | 東京都...      | 自宅            | OK     |
| ☐ | 佐藤 花子 様   | 大阪府...      | （未紐づけ）     | 除外   |
| ☐ | 鈴木 一郎 様   | ...            | 実家            | OK     |
+------------------------------------------------------------------+
| ⚠ 1 件は差出人未紐づけのため印刷対象外です。                      |
|   [住所録で差出人を紐づけてから再選択 →]                          |
+------------------------------------------------------------------+
|                              [キャンセル]  [プレビューへ進む →]   |
+------------------------------------------------------------------+
```

---

## 2. 操作

| 操作 | 挙動 |
|------|------|
| 行チェック | 複数選択（最大 200 件）。**状態「除外」行はチェック不可** |
| 差出人列 | 読み取り専用。`SenderAddressLink` の有無を表示 |
| 状態「除外」 | 紐づき無し / 差出人 archived → **チェック不可**（選択カウンタにも含めない） |
| プレビューへ進む | 有効 1 件以上必須。`resolve_print_job_items` を呼び出し |
| 除外アラート | 「N 件は差出人未紐づけのため印刷対象外です」+ 住所録編集（差出人リンク）への導線 1 行 |

---

## 3. ジョブ状態

- 選択 `addressEntryId[]` のみを `sessionStorage.printJobDraft` に保存（`printJobId` は**保存しない**）
- ページリフレッシュ時は本画面へ戻す（state 喪失防止）
- archived `AddressEntry` は一覧に表示しない（既存一覧方針）

---

## 4. 遷移

- 有効件数 0 → 進めない
- 有効件数 ≥ 1 → PRT002（省略可）→ PRT003
