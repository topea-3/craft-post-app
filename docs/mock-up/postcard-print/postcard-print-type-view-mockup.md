## 2. 操作

| 操作 | 挙動 |
|------|------|
| 入場 | デフォルト `nenga`。`sessionStorage.printPostcardType` があれば復元 |
| 種別変更 | `printPostcardType` を更新。`resolve_send_year` で Info 表示を切替 |
| 宛名選択画面へ | `/print/select` へ遷移 |
| キャンセル | 印刷フロー離脱（draft 破棄は PRT001 方針に準拠） |
