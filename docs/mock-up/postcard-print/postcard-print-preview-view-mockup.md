## 2. 操作

| 操作 | 挙動 |
|------|------|
| 種別セレクト | テンプレート定数切替。未保存 offset は確認 |
| キャンバス上ドラッグ | 選択レイヤーの offset 変更。**結果座標**（基準原点 + offset）が印刷可能範囲内に収まるようクランプ |
| 基準に戻す | 選択レイヤーまたは全体の offset を 0 に |
| レイヤー ON/OFF | セッションのみ。PDF 生成時に反映 |
| 調整を保存 | `print_layout_preferences` に書き込み（クランプ済み） |
| 印刷 | 全件再スナップショット → **新規 `printJobId` 発行** → PDF 生成 → **成功時**送付記録 → PDF 保存 / OS 印刷（任意）→ `printJobId` 破棄 |
| ページ送り | 一括時。宛名ごとに紐づき差出人が異なる |

---

## 3. エラー表示

- 再スナップショット失敗（archived 等）: 「印刷対象に無効な宛名が含まれています」— all-or-nothing で停止
- PDF 生成失敗: 「PDF の生成に失敗しました」（送付記録なし）
- 送付記録失敗: 「PDF は生成済みですが、送付記録に失敗しました。再試行してください」（同一 `printJobId` で冪等再試行）
- 再印刷（位置微調整後）: 新 `printJobId` → 新しい送付行が作成される（意図した動作）

---

## 4. プレビューと PDF の関係

- 調整 UI = HTML キャンバス（操作しやすさ優先）
- 印字結果 = スパイク結果に応じ react-pdf または html2canvas
- 座標は共通 `layoutSpec` 経由。実寸 PDF を正とし、±1mm 以内を手動確認する
