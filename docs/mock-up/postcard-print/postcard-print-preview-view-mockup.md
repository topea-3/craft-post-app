## 2. 操作

| 操作 | 挙動 |
|------|------|
| キャンバス上ドラッグ | 選択中レイヤーの位置オフセット変更（pt） |
| レイヤー ON/OFF | セッション内のみ。PDF 生成時に反映 |
| 調整を保存 | `print_layout_preferences` に書き込み |
| 種別変更 | テンプレート定数切替。未保存オフセットは確認ダイアログ |
| 印刷 | 種別ダイアログ（未選択時）→ PDF 生成 → OS 印刷 → 送付記録 |
| ページ送り | 一括印刷時。差出人は全ページ共通（v1） |
