# はがき宛名面 差出人確認モック（v1）

- **画面 ID**: `PRT002`
- **画面名**: 差出人確認（読み取り専用）
- **設計書**: [postcard-address-print-v1-design.md](../../design/postcard-address-print-v1-design.md)

---

## 1. 目的

PRT001 で除外後の**有効な印刷対象**について、宛名と紐づき差出人の対応をユーザーに確認させる。差出人の**手動変更・リンク更新は行わない**（SEN005 は使用しない）。

実装簡略化のため本画面は**省略可**（PRT001 から直接 PRT003 へ遷移してもよい）。

---

## 2. 画面レイアウト

```
+------------------------------------------------------------------+
| 印刷内容の確認                                                    |
+------------------------------------------------------------------+
| 以下の宛名と差出人で印刷します。                                   |
|                                                                   |
| | 宛名           | 差出人（紐づき）     | 住所（抜粋）          | |
| | 山田 太郎 様   | 自宅 / 山田 一郎    | 東京都渋谷区...       | |
| | 鈴木 次郎 様   | 実家 / 鈴木 太郎    | 神奈川県...           | |
+------------------------------------------------------------------+
| 除外された宛名（参考）: 佐藤 花子 様 — 差出人未紐づけ              |
+------------------------------------------------------------------+
|                              [戻る]  [プレビューへ →]             |
+------------------------------------------------------------------+
```

---

## 3. 操作

| 操作 | 挙動 |
|------|------|
| プレビューへ | PRT003。種別は PRT003 入場時に選択 |
| 戻る | PRT001 |

**禁止**: 差出人のラジオ選択、SenderAddressLink の更新、`set_sender_for_address_entry` 相当の呼び出し
