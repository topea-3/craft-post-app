## AddressEntry 年賀状送付対象の見直しモック（v1）

- **画面ID**: `ADDR005`
- **画面名**: 年賀状送付対象の見直し
- **パス**: `/addresses/nenga-target-review`（`addresses/:id` より前に登録する）
- **設計書**: [nenga-send-target-v1-design.md](../../design/nenga-send-target-v1-design.md)
- **遷移元**: 住所録一覧（`ADDR001`）の「年賀状送付対象の見直し」

---

### 1. 画面レイアウト

```
+------------------------------------------------------------------+
| 年賀状送付対象の見直し                                             |
| 年賀状年 [2026]                                                   |
| 選択した年の年賀状を受け取っておらず、その前年の喪中もない、        |
| 年賀状送付対象の宛名です。                                         |
+------------------------------------------------------------------+
| 年賀状対象外にする | 氏名+敬称        | 住所                        |
| ☑                 | 山田 太郎 様     | 東京都渋谷区...              |
| ☑                 | 佐藤 花子 様     | 大阪府...                    |
+------------------------------------------------------------------+
|                              [年賀状送付対象外にする]              |
+------------------------------------------------------------------+
```

見出しのチェックは、今のページではなく読み込んだ全候補をまとめて ON/OFF する。表示は 20 件ずつ。チェックはページを移動しても残る。

---

### 2. 初期状態

- 年賀状年の初期値は、端末ローカルの今日の西暦年（`getFullYear()`）。UTC の年は使わない。
- 入力範囲は 1900〜2100。
- 一覧は次をすべて満たす有効な住所録。
  - `nengaSendTarget = true`
  - `receipt_year = Y - 1` の喪中受取がない
  - `receipt_year = Y` の年賀状受取がない
- 初期表示では全候補の「年賀状対象外にする」を ON にする。
- 年を変えると取り直し、新しい候補は再びすべて ON。

---

### 3. 操作

| 操作 | 挙動 |
|------|------|
| 行チェックを外す | その宛名は一括更新しない |
| 年賀状送付対象外にする | チェック 0 件では押せない。確認「選択した N 件の年賀状送付対象を外します。よろしいですか？」のあと、チェック済みのフラグを FALSE にする |
| 成功 | 同じ画面で再取得。対象外になった行は一覧から消える |
| 戻る | 住所録一覧（`ADDR001`） |

受取の有無はボタン押下時に再判定しない。確認後に有効かつまだ対象のものだけを FALSE にする。

---

### 4. 空・失敗

- 候補 0 件: 「この年賀状年で、送付対象を外す候補はありません。」
- 取得失敗: 「見直し一覧の取得に失敗しました。時間をおいて再度お試しください。」
- 更新 0 件: 「更新できる宛名がありませんでした。」
- 更新成功: 「N 件を年賀状送付対象外にしました。」すでに対象外やアーカイブ済みで飛ばした件数があれば、その旨を続ける。
