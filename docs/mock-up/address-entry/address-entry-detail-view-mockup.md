## AddressEntry 詳細画面モック（v1）

- **画面ID**: `ADDR004`
- **画面名**: 住所録詳細

---

### 1. 画面レイアウト（読み取り専用ビュー）

- **上部エリア**
  - 左上: 画面タイトル「住所録詳細」
  - タイトル直下（大きめ表示）:
    - 宛先表示名（氏名＋連名）
    - 例: `山田 太郎・花子`
  - 右上: ボタン群
    - 「編集」ボタン（Primary）
    - 「アーカイブ」メニュー（もしくはセカンダリボタン）
    - 「戻る」リンク（一覧へ）
- **内容エリア**
  - 2 カラムまたはカード風レイアウトで情報を表示。

#### 1.1 基本情報ブロック


| ラベル       | 表示内容                        | 対応ドメイン                                           |
| --------- | --------------------------- | ------------------------------------------------ |
| 主たる氏名     | 例: `山田 太郎`                  | `primaryName.display`                               |
| 主たる氏名（カナ） | 例: `ヤマダ タロウ`                | `primaryName.displayKana` |
| 連名        | 例: `山田 花子`, `山田 三郎` （改行区切り） | `coRecipients[].display`                            |
| 敬称        | 例: `様`                      | `honorific`                                      |


#### 1.2 住所情報ブロック

| ラベル          | 表示内容              | 対応ドメイン             |
|-----------------|-----------------------|--------------------------|
| 郵便番号        | 例: `123-4567`       | `PostalCode.formatted`   |
| 都道府県        | 例: `東京都`          | `Address.prefecture`     |
| 市区町村        | 例: `渋谷区`          | `Address.city`           |
| 町名・番地      | 例: `神南 1-1-1`      | `Address.street`         |
| 建物名・部屋番号| 例: `○○ビル 3F`      | `Address.building`       |


#### 1.3 メモブロック

- ラベル: 「メモ」
- コンポーネント: 読み取り専用テキスト（複数行）
- 内容: `Memo.text`

#### 1.4 システム情報ブロック


| ラベル    | 表示内容                  | 対応ドメイン      |
| ------ | --------------------- | ----------- |
| ID | UUID | `id`|   
| 作成日時   | 例: `2026/03/10 08:34` | `createdAt` |
| 最終更新日時 | 例: `2026/03/11 12:01` | `updatedAt` |
| ステータス  | 例: `有効` / `アーカイブ済み`   | `archivedAt`（未設定＝有効。API では `archived` 真偽でも可） |

#### 1.5 紐づき差出人（読み取り専用）※任意

- 差出人が紐づいている場合:
  - 表示: `SenderLabel.value` / `joinRecipients(primaryName, coRecipients)`
  - 住所・郵便番号は必要なら補足表示（`PostalCode.formatted` / `Address.toSingleLine()`）
- 紐づきがない場合:
  - 「差出人未設定」

---

### 2. アクション・遷移

- **編集ボタン**
  - クリック → 編集画面（`ADDR003`）へ遷移。
- **アーカイブ操作**
  - 「アーカイブ」選択 → 確認ダイアログ:
    - 「この住所録エントリをアーカイブしますか？一覧からは非表示になりますが、データは保持されます。」
  - 実行後:
    - ステータス表示を「アーカイブ済み」に変更。
    - 一覧画面からは非表示（`archivedAt` が設定された状態）。
    - 詳細画面自体へアクセス可能かどうかは要件次第（v1 では URL 直打ち用に参照可としてもよい）。
- **戻るリンク**
  - 一覧画面（`ADDR001`）へ戻る。
