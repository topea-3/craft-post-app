## PostcardSend 一覧画面モック（v1）

- **画面ID**: `SND001`
- **画面名**: 送付履歴一覧
- **設計書**: `docs/design/postcard-send-v1-design.md`

---

### 1. 画面レイアウト（テーブル一覧）

- **上部エリア**
  - 左上: 画面タイトル「送付履歴」
  - その下: タブ「履歴」|「送付状況」（本モックは履歴タブ。送付状況は `SND005`）
  - 右上: ボタン群
    - 「新規作成」ボタン（Primary）→ `SND002`
    - 「一括登録」ボタン → `SND006`
    - 「フィルタ」トグル
- **検索・フィルタエリア（折りたたみ可）**
  - フリーテキスト検索
    - プレースホルダ: 「宛名・差出人・メモで検索」
  - 送付年セレクト
    - option: `{ 全期間 } ∪ { 今年 } ∪ list_postcard_send_years`（受取 `buildYearOptions` と同型）
    - デフォルト: **全期間**
    - 選択中の年が API 年一覧から消えても option に残す
  - 種別セレクト: 全種別 / 年賀状 / 喪中はがき
  - 登録経路セレクト（任意）: すべて / 印刷 / 手入力
- **フィルタ state**: 送付状況タブ（SND005）と**独立**（対象年・受取年・sent/unsent を持ち越さない）
- **一覧テーブル**
  - 行クリック: 詳細（`SND004`）
  - 右端: 編集 / 削除
  - ページネーション: `PaginationControls`

#### テーブルカラム案

| 順序 | カラム名 | 内容 | 備考 |
| --- | --- | --- | --- |
| 1 | 送付日 | `sentOn` | 例: `2026/01/03` |
| 2 | 種別 | `postcardType` 表示名 | バッジ可 |
| 3 | 宛名 | スナップショット氏名 / live 補完 | 太字 |
| 4 | 差出人 | スナップショット氏名 or ラベル | |
| 5 | 経路 | `source` | 印刷 / 手入力 |
| 6 | メモ（抜粋） | `memo` 先頭 30 **コードポイント**（UTF-16 `slice` 禁止） | |
| 7 | 操作 | 編集 / 削除 | |

- **表示対象**: `deletedAt` 未設定
- **デフォルトソート**: `sentOn` 降順

---

### 2. アクションと遷移

- **新規作成** → `SND002`
- **一括登録** → `SND006`
- **送付状況タブ** → `SND005`（同一シェル）
- **行クリック** → `SND004`
- **編集** → `SND003`
- **削除**: 確認後、論理削除 → 一覧から非表示

---

### 3. 状態・UI 挙動メモ

- **空状態**: 「まだ送付履歴がありません。」+ 新規作成 / 印刷への導線
- **検索 0 件**: 「該当する送付履歴が見つかりませんでした。」+ 条件クリア
