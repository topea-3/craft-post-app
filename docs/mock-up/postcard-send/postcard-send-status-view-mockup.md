## PostcardSend 送付状況画面モック（v1）

- **画面ID**: `SND005`
- **画面名**: 送付状況
- **設計書**: `docs/design/postcard-send-v1-design.md` §5.1.4

---

### 1. 画面レイアウト

- **上部**: タイトル「送付履歴」+ タブ「履歴」|「送付状況」（本モックは送付状況タブ）
- **フィルタ（常時表示）**
  - 対象年（必須セレクト。デフォルトは今年）
  - 種別: すべて / 年賀状 / 喪中はがき
  - 表示: セグメント「送っていない」|「送った」（デフォルト: 送っていない）
  - チェック: 「この年に受取履歴がある相手に限定」（ON 時 `receiptYear = 対象年`）
  - 検索: 住所録表示名
- **一覧**
  - カラム: 宛名 / 住所抜粋 / 最終送付日（送った側） / 送付件数 / 操作
  - ページネーション

---

### 2. 一括操作（未送付表示時）

- 行チェック（最大 200）
- 「選択して印刷」→ `printJobDraft` に ID を載せて PRT001（または PRT002）へ
- 「選択して一括登録」→ `SND006` に選択 ID を引き継ぎ

---

### 3. 状態メモ

- **空（未送付 0）**: 「この条件では未送付の相手はいません。」
- **空（送付済 0）**: 「この条件では送付記録がありません。」
- 受取限定 ON かつ受取 0 件: 「受取履歴のある相手がいません。」
