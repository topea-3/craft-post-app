## PostcardSend 送付状況画面モック（v1）

- **画面ID**: `SND005`
- **画面名**: 送付状況
- **パス**: `/sends?tab=status`
- **設計書**: `docs/design/postcard-send-v1-design.md` §5.1.4 / §5.4.4

---

### 1. 画面レイアウト

- **上部**: タイトル「送付履歴」+ タブ「履歴」|「送付状況」（本モックは送付状況タブ）
- **フィルタ（常時表示）**
  - 対象年（必須セレクト。デフォルトは今年）— 送付判定の年
    - option: `{ 今年, 今年-1 } ∪ list_postcard_send_years ∪ { 現在の対象年 }`（**全期間なし**。years 失敗時も選択値を残す）
  - 種別: すべて / 年賀状 / 喪中はがき
  - 表示: セグメント「送っていない」|「送った」（デフォルト: 送っていない）
  - チェック: 「受取履歴のある相手に限定」— **初期 ON**
  - 受取年セレクト: チェック ON のとき表示・有効。**対象年と独立**
    - option: `{ 対象年, 対象年-1 } ∪ list_postcard_receipt_years ∪ { 現在の receiptYear }`（デフォルト `対象年 - 1` と現在値は必ず含む）
    - チェック OFF 時は API に `receiptYear` を送らない（hidden 値は保持可）
    - 対象年変更時（OFF 中も含む）: **未手動なら** `対象年 - 1` に追従。**手動変更済みは OFF→ON でも維持**
  - 検索: 住所録表示名
- **一覧**
  - カラム: 宛名 / 住所抜粋 / 最終送付日 / 送付件数 / 操作
  - 最終送付日・送付件数: **両タブで表示**。窓は年フィルタ外（種別フィルタ連動）。設計書 §5.1.4
  - ページネーション: **20 件/ページ**。ソートは **kana 昇順** + id（住所録 / PRT001 と同じ）

---

### 2. 一括操作（未送付表示時）

- 行チェック
  - 選択 ID は **ページ・検索を跨いで保持**（挙動は PRT001 に似せる）
  - 保持先は **専用 React state**（または `sendStatusSelectedIds`）。**`printJobDraft` は触らない**
  - **対象年 / 種別 / 受取限定（チェック・受取年） / sent·unsent 切替** で専用選択だけクリア
  - 上限 200。**201 件目は追加不可**（黙って clamp しない）
- 「選択して印刷」
  - 常に **PRT001**（`/print/select`）へ
  - **確認 OK 時だけ** `printJobDraft.addressEntryIds` を **置換**。既存 draft が空でないときは確認ダイアログ。**キャンセル時は draft 非変更・非遷移**
  - 種別が年賀状/喪中のとき `sessionStorage.printPostcardType` も同期。「すべて」のときは変更しない
  - 引渡し時の 200 clamp はセーフティネットとして残してよい
- 「選択して一括登録」→ `SND006` へ **router state**（等）で ID・種別を渡す。**`printJobDraft` は使わない**。送付日は今日

---

### 3. 状態メモ

- **空（未送付 0・keyword 空）**: 「この条件では未送付の相手はいません。」
- **空（送付済 0・keyword 空）**: 「この条件では送付記録がありません。」
- **keyword 非空で 0 件**: 「該当する相手が見つかりませんでした。」+ 検索クリア（印刷/登録の誤誘導を出さない）
- 受取限定 ON かつ受取 0 件: 「受取履歴のある相手がいません。」
- アーカイブ済み住所録は一覧に出ない（履歴タブで確認）
- 受取限定は年のみ（送付種別と受取 `category` は連動しない）
