## PostcardSend 一括登録画面モック（v1）

- **画面ID**: `SND006`
- **画面名**: 送付履歴一括登録
- **設計書**: `docs/design/postcard-send-v1-design.md`

---

### 1. 画面レイアウト

- **上部**: 「送付履歴一括登録」/ 「キャンセル」

#### ステップ（同一画面内でも可）

1. **宛名選択**: 住所録の複数選択 UI（最大 200）。SND005 からの引き継ぎ（**router state**。`printJobDraft` ではない）があれば初期チェック
2. **共通属性**: 送付日・種別・メモ（全件共通）。SND005 から種別を引き継いだ場合は初期値に反映。送付日デフォルトは今日
3. **差出人確認（読み取り専用表）**: 各宛名のリンク差出人を一覧。未紐付け・archived はエラー行としてハイライト

---

### 2. アクション

- **登録**: エラー行が **0 のときのみ**有効（除外して続行しない）→ `create_postcard_sends_manual_batch` → `SND001`
- 登録中はボタン disabled
- **キャンセル**: **referrer 固定** — SND005 から来た場合は `SND005`（`/sends?tab=status`）、それ以外（ナビ直等）は `SND001`
- エラー行がある場合: 「差出人を紐づけてから再試行」導線（差出人一覧 / リンク編集へ）

---

### 3. バリデーション・UX

| 条件 | 挙動 |
| --- | --- |
| 0 件選択 | 登録不可 |
| 201 件以上 | 選択時に上限エラー |
| 同一宛名の重複選択 | Validation エラー（dedupe しない） |
| 未紐付け差出人あり | **ブロック**。登録ボタン disabled + 件数サマリ。印刷の「除外して継続」とは異なる |
| 未来の送付日 | フォーム Validation |
| メモ超過 | 「メモは 1000 文字以内で入力してください。」 |

- ヘルプ: 「印刷と同時に記録する場合は、印刷フローを使ってください。」
