## PostcardSend 一括登録画面モック（v1）

- **画面ID**: `SND006`
- **画面名**: 送付履歴一括登録
- **設計書**: `docs/design/postcard-send-v1-design.md`

---

### 1. 画面レイアウト

- **上部**: 「送付履歴一括登録」/ 「キャンセル」

#### ステップ（同一画面内でも可）

1. **宛名選択**: 住所録の複数選択 UI（最大 200）。SND005 からの引き継ぎがあれば初期チェック
2. **共通属性**: 送付日・種別・メモ（全件共通）
3. **差出人確認（読み取り専用表）**: 各宛名のリンク差出人を一覧。未紐付け・archived はエラー行としてハイライト

---

### 2. アクション

- **登録**: エラー行が 0 のときのみ有効 → `create_postcard_sends_manual_batch` → `SND001`
- **キャンセル** → `SND001` または `SND005`
- エラー行がある場合: 「差出人を紐づけてから再試行」導線（差出人一覧 / リンク編集へ）

---

### 3. バリデーション・UX

| 条件 | 挙動 |
| --- | --- |
| 0 件選択 | 登録不可 |
| 201 件以上 | 選択時に上限エラー |
| 未紐付け差出人あり | all-or-nothing。登録ボタン disabled + 件数サマリ |
| 未来の送付日 | フォーム Validation |

- ヘルプ: 「印刷と同時に記録する場合は、印刷フローを使ってください。」
