## PostcardSend 編集画面モック（v1）

- **画面ID**: `SND003`
- **画面名**: 送付履歴編集
- **設計書**: `docs/design/postcard-send-v1-design.md`

---

### 1. 画面レイアウト

- **上部**: 「送付履歴編集」/ 「キャンセル」（詳細または一覧へ）

#### 編集可能

| 項目 | UI | 備考 |
| --- | --- | --- |
| 送付日 | date | 未来日不可 |
| 種別 | select | 年賀状 / 喪中はがき |
| メモ | textarea | 任意 |

#### 読み取り専用（変更不可の説明付き）

| 項目 | 表示 |
| --- | --- |
| 宛名 | スナップショット表示名 + 住所録へのリンク（可能な場合） |
| 差出人 | スナップショット表示名 |
| 登録経路 | 印刷 / 手入力 |
| 登録日時 | `createdAt` |

- 宛名・差出人を変えたい場合の注記: 「削除してから新規登録してください。」

---

### 2. アクション

- **保存** → `update_postcard_send` → `SND004`
- **キャンセル** → 元画面

---

### 3. バリデーション

作成画面と同じ日付・種別ルール。楽観ロックが必要なら `expectedUpdatedAt`（受取更新に準拠）。
