## PostcardSend 詳細画面モック（v1）

- **画面ID**: `SND004`
- **画面名**: 送付履歴詳細
- **設計書**: `docs/design/postcard-send-v1-design.md`

---

### 1. 画面レイアウト

- **上部**: 「送付履歴詳細」/ 「編集」/ 「削除」/ 「一覧へ」

#### 表示セクション

1. **送付情報**: 送付日、種別、経路、メモ
2. **宛名（スナップショット）**: 郵便番号、住所、氏名・連名・敬称。住所録が active なら「住所録を開く」リンク
3. **差出人（スナップショット）**: 郵便番号、住所、氏名。差出人が active なら「差出人を開く」リンク
4. **メタ**: ID、`printJobId`（折りたたみ可）、作成・更新日時

---
