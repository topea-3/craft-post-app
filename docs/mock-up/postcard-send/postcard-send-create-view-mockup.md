## PostcardSend 作成画面モック（v1）

- **画面ID**: `SND002`
- **画面名**: 送付履歴新規作成
- **設計書**: `docs/design/postcard-send-v1-design.md`

---

### 1. 画面レイアウト（フォーム）

- **上部**: タイトル「送付履歴新規作成」/ 「キャンセル」（一覧へ）

#### 1.1 送付情報

| 項目名 | UI | 対応 | 備考 |
| --- | --- | --- | --- |
| 送付日 | date input | `sentOn` | **必須**。未来日不可。デフォルトは今日 |
| 種別 | select | `postcardType` | **必須**。年賀状 / 喪中はがき |
| メモ | textarea | `memo` | 任意。最大 1000 文字 |

#### 1.2 宛名・差出人

| 項目名 | UI | 対応 | 備考 |
| --- | --- | --- | --- |
| 宛名 | AddressEntry 選択 | `addressEntryId` | **必須**。active のみ |
| 差出人 | SenderEntry 選択 | `senderEntryId` | **必須**。宛名選択後、リンクがあれば自動セット。手動変更可 |

- 宛名変更時: 差出人をリンク結果で上書き（ユーザーが手動変更済みの場合は確認ダイアログ）

---

### 2. ボタン・アクション

- **キャンセル** → `SND001`
- **保存** → `create_postcard_sends_manual_batch`（1 件）→ `SND004` または一覧

---

### 3. バリデーション

| 条件 | メッセージ |
| --- | --- |
| 送付日未入力 | 「送付日を入力してください。」 |
| 未来日 | 「送付日に未来の日付は指定できません。」 |
| 宛名未選択 | 「宛名を選択してください。」 |
| 差出人未選択 / 解決不可 | 「差出人を選択してください。」 |
| 宛名/差出人 archived | 「選択した宛名（差出人）はアーカイブ済みです。」 |

---

### 4. UX メモ

- 印刷で送る場合は本画面ではなく印刷フローを案内（ヘルプテキスト 1 行）
- 編集（`SND003`）と共通フォームのうち、宛名・差出人は作成時のみ編集可
